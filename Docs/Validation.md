# 真实样本验收与测试记录

## 测试入口

从 `Examples/IDCardDemo` 或 `Examples/IDCardDemoPods` 启动 App，点击“选择身份证照片”，分别选择正面、反面、已裁剪图与背景中包含身份证的照片。正面应展示字段、号码校验、标准图与可检测到的人脸头像；反面应展示签发机关和有效期限。对于模糊、缺角、无证件和号码不合法的照片，应显示明确失败信息。切到后台再返回、连续选择多张图片，也应能正常工作。

## 样本集

在授权和脱敏条件下采集 100～300 张正反面样本，覆盖正常光照、弱光、强光、反光、倾斜、旋转、复杂背景、远近距离、不同设备、扫描件和截图。原始身份证图与逐字段标注应使用受控存储，不纳入 Git 仓库，不在日志或测试输出中打印个人信息。

## 记录指标

逐张记录：设备与 iOS 版本、输入类型、处理耗时、正反面判断、姓名、性别、民族、出生日期、住址、号码、签发机关、有效期限、头像提取、错误码与人工标注。分别计算各字段准确率、整卡成功率、误成功率、P50/P95 耗时，以及不同拍摄条件的分组结果。

需求文档的目标值是：清晰完整样本的号码 ≥99%、姓名 ≥98%、性别和生日 ≥99%、民族 ≥98%、地址 ≥95%、正反面 ≥99%、头像提取 ≥98%。这些只是验收目标，目前没有真实样本结果，不应写成已达标。

## 已完成的自动验证

4 项自动测试覆盖号码 MOD 11-2、日期、正反面关键词、字段解析，以及一张程序生成的虚构正面图走完整个 Vision OCR 流程。构建验证覆盖 SPM 库、SPM 示例 App、CocoaPods 示例 App 和真机/模拟器 XCFramework。自动测试不替代真实设备与真实样本验收。
